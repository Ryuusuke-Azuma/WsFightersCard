# プロジェクト概要: WsFightersCard

## 1. コンセプト

ヴァイスシュヴァルツ（Weiβ Schwarz）プレイヤーが、日々の対戦結果を簡単かつ詳細に記録・分析し、自身の成長と戦略立案を支援するためのモバイルアプリケーション。

「**モダン ＆ クリーン**」をデザインコンセプトとし、直感的な操作性と高度な分析機能を両立します。

## 3. デザイン・ブランド

- **アプリアイコン**: ノート（記録）と円グラフ（分析）を組み合わせた、アプリの本質を象徴するデザイン。
- **配色**: 
  - メインテーマ: ライト・モノトーン（白背景にチャコールグレーのアクセント）。
  - アクセントカラー: 信頼感のあるブルー。
- **UIスタイル**: 
  - Material 3 に準拠した、システムカラーと調和するクリーンなインターフェース。
  - **画面方向**: 縦画面（Portrait）固定。

## 4. ナビゲーション・ポリシー

ユーザーが迷わず、かつストレスなく操作できるよう、以下のナビゲーションルールを適用します。

- **メインメニュー遷移**: サイドドロワーから「スケジュール」「戦績分析」「プロフィール」を選択した際、バックスタック（遷移履歴）はクリアされます。これにより、どのメイン画面からでもBackボタン一回でアプリを終了（またはドロワーを閉じる）ことができます。
- **詳細画面遷移**: メイン画面から「設定」などの詳細画面へ遷移した場合は、バックスタックに保存されます。Backボタンを押すと、遷移元のメイン画面に戻ります。
- **重複遷移の防止**: 現在表示中の画面と同じメニュー項目を選択した場合は、画面の再生成を行いません。

## 6. 対象ユーザー

- 日々のフリー対戦やショップ大会の結果を記録したいカジュアルプレイヤー
- 大会に向けて、自身のデッキの強みや弱みをデータで分析したい競技プレイヤー
- 複数のデッキのパフォーマンスを管理したいデッキビルダー
